# model (hd-model): boards 3D, variantes A/B/C derriere un selecteur

- `rendering/models/model-variants.js` (nouveau): `window.__MV='scout:B,king:C,guard:A,engineer:B,envoy:A,observatory:C,forge:C,granary:C,sanctuary:C'` (cle:LETTRE, virgule ou espace). Sans cle = modele de production. `MV_DEFAULT` = meme chose en dur apres le choix du Roi. `__MV` doit etre pose AVANT le premier build des modeles (cache `UM` de unit-instances.js et `GEO` de structures.js, hors perimetre, non indexes par `__MV`): init script / avant le chargement du jeu.
- `unit-variants.js` (nouveau): scout, engineer, envoy remplacent le kit (boites, pas encore pixel-texturees); king (couronne haute) et guard (crete plate) se dessinent par-dessus pxKing / pxGuard; guard remplace son ecu par `guardPavois(v)` (r.shield). Hooks: `humanKit` dans units.js (wrapper autour de `humanKit0`, inchange) et `r.shield` du guard. `bastion-buildings.js`: `mvRoof()` (toit par fonction: economie vert, defense bleu, guerre rouge, ville or) + `mvMarker()` (repere haut unique par batiment, hors emprise des murs, dans le socle 2x2).
- Planches: `docs/studio-boards/model/` (`spec.json`, `rowN_{X,A,B,C}.png`; X = modele actuel). Regenerer: `npm run build`, `python3 docs/studio-boards/model/_src/make_script.py`, `python3 docs/studio-boards/model/_src/render.py [0 A B C]`, `python3 docs/studio-boards/model/_src/compose.py` (machine chargee: compter 5 min par variante).
