Planches à valider

Deux planches. Répondez pour chacune avec son nom devant, par exemple « Armes : 1B 2B … » et « Blocs : 1B 3C … ». Rien n'est appliqué tant que vous n'avez pas répondu.

Armes et outils12 lignes : épées, hallebarde, arc, boucliers, outils, charges, étendard, canon. A = actuel, B = nouveau. Monde en blocs9 lignes : terrain, falaises, arbres, décor, textures des bâtiments, saisons. A = actuel, B = bloc de 0,5, C = bloc de 1/3.
